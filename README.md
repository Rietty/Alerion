This repository consists of all my solutions to [Everybody Codes](https://everybody.codes/home), a yearly programming challenge.

- All solutions in this repository are written in Python 3.14.
- I use the following packages for general quality:
  - [`ruff`](https://github.com/astral-sh/ruff) for for linting and formatting.
  - [`mypy`](https://github.com/python/mypy) for static typing enforcement.
